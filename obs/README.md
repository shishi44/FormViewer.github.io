# FormViewer OBS

## ブラウザソース

管理画面の「OBSで使う」からURLをコピーし、OBSの「ソース追加 → ブラウザ」のURLへ貼り付けます。
推奨サイズは 1000 x 650 です。ページ背景は透明なのでクロマキーは不要です。

## ローカルHTML

「OBS用HTMLを保存」から書き出したHTMLを、OBSブラウザソースの「ローカルファイル」で選択できます。
このHTMLは書き出し時点の回答を埋め込んだスナップショットです。

## ホットキー

`formviewer-hotkeys.lua` を OBS の「ツール → スクリプト」から追加します。
Browser Source名をOBS上のソース名と一致させた後、「設定 → ホットキー」で前/次を割り当てます。
