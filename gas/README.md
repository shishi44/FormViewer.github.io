# Google Apps Script セットアップ

## 推奨方式: 回答先スプレッドシートに紐づける

1. Googleフォームの「回答」から回答先スプレッドシートを開く。
2. スプレッドシートで **拡張機能 → Apps Script** を開く。
3. `Code.gs` の内容を貼り付ける。
4. `CONFIG.SHEET_NAME` が実際の回答シート名と一致することを確認する。
5. `SPREADSHEET_ID` は空のままでよい（紐づけスクリプトの場合）。
6. Apps Script のプロジェクト設定でタイムゾーンを Asia/Tokyo にする。
7. **デプロイ → 新しいデプロイ → ウェブアプリ** を選択する。
8. 実行ユーザーとアクセス範囲を運用方針に合わせて設定する。
9. 発行された `/exec` URLを `js/config/appConfig.js` の `gasWebAppUrl` に設定する。
10. `dataSource` を `"gas"` に変更する。

## 必須ヘッダー

- `タイムスタンプ`（存在しない場合でも動作するが推奨）
- `お名前(ラジオネーム)`
- `内容`

列番号ではなくヘッダー名で判定するため、列の位置は固定されません。

## JSONP

通常の `fetch()` がCORS等で失敗した場合、フロントエンドは設定によりJSONPへフォールバックできます。
JSONPは公開可能な読み取り専用回答だけに使用してください。

## セキュリティ

このAPIには更新・削除処理を実装していません。スプレッドシートID、OAuthトークン、例外スタックもレスポンスへ含めません。
公開Web Appとして運用する場合、返却する回答データは第三者が取得できる可能性があるものとして扱ってください。
