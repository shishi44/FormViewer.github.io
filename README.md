# パワラジフォーマット

Googleフォームの回答を読み込み、配信・画面表示向けテンプレートへ整形するGitHub Pages対応ビューアーです。

## 初心者向けの使い方
1. Googleフォームの回答先をGoogleスプレッドシートにします。
2. スプレッドシートの共有を「リンクを知っている全員 / 閲覧者」にします。
3. パワラジフォーマットを開き、「GoogleスプレッドシートURL」を貼ります。
4. 「お名前」「内容」に使う列を確認して接続します。

GASの作成・デプロイは不要です。

## 確認済み管理
回答一覧は「すべて / 確認済み / 未確認」の3タブで管理できます。確認状態はブラウザのlocalStorageへ保存されます。未確認タブのチェックボックス、プレビュー上部の「確認済み」、または「#1〜#94」のような一括範囲指定で確認済みにできます。ヘッダーの件数は未確認件数です。

## OBS
### ブラウザソースURL + ホットキー
透明背景のBrowser Sourceを使います。`obs/formviewer-hotkeys.lua` を追加すると、OBS側で「前/次」「本文を上/下」「先頭へ」を操作できます。Google Sheets自動再取得時も、同じお便りならOBS側スクロール位置を維持します。

### ウィンドウキャプチャ
管理画面の「OBSで使う」から専用キャプチャ画面を開けます。テンプレートと同化しにくいキー背景色を緑・青・マゼンタから自動選択します。同じブラウザ内では、選択中のお便り・本文スクロール・表示設定を専用画面へ同期します。

### OBS用HTML
現在の回答とデザインを単一HTMLへ書き出せます。CSVでも利用できますが、書き出した時点のスナップショットです。
